# ویتارا — اپلیکیشن فارسی دانش ویتامین

نسخه ۱٫۰ · تاریخ آماده‌سازی: ۱۶ اکتبر ۲۰۲۶

ویتارا یک اپلیکیشن قابل اجرا و مستقل، با رابط کاملاً فارسی و راست‌به‌چپ است. هدف نسخه حاضر، آموزش و مقایسه دریافت ثبت‌شده با مقادیر مرجع غذایی بزرگسالان سالم است. محاسبات واقعی‌اند و به سرویس هوش مصنوعی یا کلید API نیاز ندارند.

## امکانات پیاده‌سازی‌شده

- صفحه اصلی، منوی واکنش‌گرا و فونت فارسی Vazirmatn به‌صورت محلی.
- دانشنامه هر ۱۳ ویتامین ضروری با نقش، متابولیسم، کمبود، احتیاط، ارزیابی آزمایشگاهی و شکل مکمل.
- جست‌وجوی نام فارسی/انگلیسی، نقش و غذا؛ فیلتر محلول در آب، چربی، گروه B و نشان‌شده‌ها.
- صفحه مستقل هر ویتامین و پیوند مستقیم منبع NIH ODS.
- ۳۹ **رکورد غذا–ویتامین** با سهم مشخص؛ این تعداد، ۳۹ غذای منحصربه‌فرد یا پایگاه کامل ترکیب غذا نیست.
- محاسبه دریافت همان ویتامین از غذا، مکمل و بخش افزوده غذای غنی‌شده.
- انتخاب مرجع بر اساس سن و گروه فیزیولوژیک؛ بارداری/شیردهی ۱۹ تا ۵۰ سال؛ تعدیل C برای سیگار.
- تبدیل IU ویتامین D، تبدیل اسیدفولیک همراه غذا به DFE و تفکیک دامنه UL.
- نمایش هم‌زمان تفاوت UL آمریکا و EFSA برای B6؛ انتخاب کامل استاندارد اروپایی فعال نیست.
- مقایسه دو تا چهار ویتامین.
- مرور هفت گروه دارویی منتخب و سه عامل خطر تغذیه‌ای/آزمایشگاهی با منبع.
- فضای کار، گزارش دریافت، چاپ یا ذخیره PDF، پشتیبان JSON و بازیابی با اعتبارسنجی.
- ذخیره اختیاری در همان مرورگر، حذف داده و کنترل رضایت کاربر.

این پروژه صفحه نمایشی با دکمه‌های بی‌عمل نیست؛ ابزارهای فهرست‌شده به موتور محاسبه و وضعیت برنامه متصل‌اند. بخش «فضای کار» نیز یک ابزار محلی گزارش‌گیری است، نه سامانه پرونده بیمار چندکاربره.

## اجرای سریع روی Windows، macOS یا Linux

۱. فایل ZIP را استخراج کنید. پوشه پروژه را در VS Code یا ترمینال باز کنید.

۲. برای استفاده از خود اپلیکیشن تنها به یک وب‌سرور فایل ساده نیاز دارید. در ویندوز، اگر Python نصب است:

```powershell
py -m http.server 3000 --directory dist
```

در macOS/Linux:

```bash
python3 -m http.server 3000 --directory dist
```

۳. در مرورگر باز کنید: <http://localhost:3000>

۴. برای توقف سرور `Ctrl+C` بزنید. بازکردن مستقیم `index.html` با دابل‌کلیک به‌علت محدودیت ماژول‌های مرورگر روش مناسبی نیست.

## بررسی پروژه با Node.js

Node.js نسخه ۲۰ یا جدیدتر نصب کنید. پروژه وابستگی اجرایی npm ندارد.

```bash
npm test
npm run check
npm run build
```

`build` آزمون‌ها و بررسی دارایی‌ها و تنظیمات را اجرا می‌کند. خروجی اپلیکیشن از ابتدا در `dist` قرار دارد و bundling لازم ندارد. راه‌اندازی با Python را می‌توان بدون Node انجام داد.

## استقرار روی Vercel از طریق GitHub

۱. یک مخزن جدید بسازید و **محتویات پوشه پروژه**، شامل `dist`، `tests`، `scripts`، `package.json` و `vercel.json` را در ریشه آن بارگذاری کنید. پوشه پروژه را به‌صورت یک فایل ZIP در مخزن قرار ندهید.

۲. در Vercel گزینه **Add New → Project** را انتخاب و مخزن را Import کنید.

۳. تنظیمات زیر را بررسی کنید. فایل `vercel.json` آن‌ها را مشخص کرده است:

| تنظیم | مقدار |
|---|---|
| Framework Preset | Other |
| Root Directory | ریشه مخزن |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install --ignore-scripts` |
| Node.js | نسخه پشتیبانی‌شده Vercel و حداقل ۲۰ |
| Environment Variables | لازم نیست |

۴. **Deploy** را بزنید. مسیرهای داخلی با `#` کار می‌کنند، بنابراین به rewrite برای مسیرهای SPA نیاز ندارند.

۵. بعد از انتشار، مسیرهای `/#vitamins`، `/#calculator/D`، `/#safety` و `/#workspace` را آزمایش کنید. روی موبایل نیز منو، فرم‌ها و جدول اسکرول‌شونده را بررسی کنید.

۶. برای دامنه شخصی به **Project → Settings → Domains** بروید و فقط رکوردهای DNS ارائه‌شده توسط Vercel را اضافه کنید. HTTPS پس از تکمیل تنظیمات میزبانی برقرار می‌شود.

۷. تغییرات بعدی را commit و push کنید تا فرایند استقرار مخزن اجرا شود. برای بازگشت از بخش Deployments یک نسخه سالم پیشین را انتخاب کنید.

مستندات رسمی: [تنظیم ساخت](https://vercel.com/docs/builds/configure-a-build)، [vercel.json](https://vercel.com/docs/project-configuration/vercel-json)، [استقرار](https://vercel.com/docs/deployments). خودِ انتشار در حساب Vercel شما در این تحویل انجام نشده است؛ پروژه برای Import آماده است.

## استقرار با Vercel CLI — اختیاری

اگر CLI رسمی را نصب کرده‌اید، از ریشه پروژه اجرا کنید:

```bash
vercel login
vercel
vercel --prod
```

احراز هویت باید توسط مالک حساب انجام شود. هیچ توکن یا اطلاعات حسابی در پروژه قرار ندهید. برای این اپلیکیشن نیازی به secret یا بانک اطلاعاتی نیست.

## شخصی‌سازی و نگهداری

- نام و متن‌های برند در `index.html` و `app.js` قرار دارند. رنگ‌ها در ابتدای `styles.css` تعریف شده‌اند.
- برای افزودن یا اصلاح محتوای علمی، ابتدا منبع اولیه را بررسی و سپس `data.js` را ویرایش کنید. تاریخ دسترسی را با تاریخ انتشار منبع اشتباه نگیرید.
- برای تغییر یک مقدار مرجع، آزمون مرتبط در `engine.test.mjs` و آزمون مرز سنی آن را به‌روزرسانی کنید. `npm run build` باید موفق باشد.
- کلید ذخیره محلی `vitara-v1` است. تغییر ناسازگار قرارداد داده نیازمند نسخه جدید و برنامه مهاجرت داده است.
- نسخه فعلی فاقد اتصال زنده USDA، حساب کاربری، سرور پرونده بالینی، داشبورد مدیریت محتوا و پاسخ‌گوی LLM است؛ معماری پیشنهادی آن‌ها در گزارش طراحی آمده است.

## حدود علمی و کاربرد

دامنه محاسبات، بزرگسالان سالم ۱۹ تا ۱۲۰ سال است. استفاده برای کودک، بیماری کلیوی، سوءجذب، کمبود تشخیص‌داده‌شده یا درمان نیازمند قواعد و نظارت جداگانه است. مقدار کمتر از RDA در یک روز، کمبود را اثبات نمی‌کند؛ کمتر بودن از AI نیز به‌تنهایی دریافت ناکافی را ثابت نمی‌کند. نبود UL یا هشدار، تضمین ایمنی نیست.

محتوا به منابع رسمی پیوند دارد، اما پیش از ارائه به‌عنوان ابزار بالینی باید توسط متخصص مسئول مرور و تأیید شود. رابط، این محدودیت را صریحاً بیان می‌کند.

## مجوز و انتساب

رابط و کد این تحویل برای توسعه و استفاده شما آماده شده‌اند. فونت Vazirmatn اثر [گروه سازندگان Vazirmatn](https://github.com/rastikerdar/vazirmatn) با مجوز SIL OFL 1.1 است؛ متن مجوز در `dist/assets/OFL.txt` قرار دارد. خلاصه‌ها بازنویسی فارسی‌اند؛ متن کامل صفحات منابع بازنشر نشده است. نشان سازمان‌ها یا ادعای تأیید آن‌ها در محصول استفاده نشده است.
