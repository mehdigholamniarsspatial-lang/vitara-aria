# گزارش کنترل کیفیت و انتشار

نسخه: ۱٫۰٫۰ — تاریخ: ۱۶ اکتبر ۲۰۲۶

## بررسی‌های اجراشده

| بررسی | نتیجه | حدود پوشش |
|---|---|---|
| نحو فایل‌های JavaScript | موفق | فایل‌های برنامه، داده و موتور |
| آزمون خودکار موتور | ۲۰ آزمون موفق | مرز سن، مرحله فیزیولوژیک، واحد، UL و ورودی نامعتبر |
| آزمون اجرای برنامه با DOM آزمایشی | ۹ آزمون موفق | مسیرها، جست‌وجو، ثبت غذا/مکمل، ایمنی، ذخیره و پشتیبان |
| دارایی‌ها و تنظیمات | موفق | HTML فارسی RTL، فایل فونت/مجوز، ارجاع محلی، خروجی Vercel |
| مرور واقعی در مرورگر | انجام نشده | ابزار مرورگر مناسب در این محیط در دسترس نبود |
| آزمون بصری موبایل و دسکتاپ | انجام نشده | قواعد واکنش‌گرا پیاده‌سازی شده‌اند؛ نیازمند مشاهده روی دستگاه |
| ممیزی WCAG و screen reader | انجام نشده | نام فرم، focus، راه پرش محتوا و پیام وضعیت در کد تعریف شده‌اند |
| بازبینی متخصص بالینی مستقل | انجام نشده | استناد به منبع جای این مرحله را نمی‌گیرد |
| استقرار در حساب Vercel مالک | انجام نشده | فایل تنظیمات و راهنمای کامل تحویل شده است |

آزمون DOM ساده، آزمون مرورگر یا rendering نیست. عبور آزمون‌ها تأیید محاسبات نمونه و جریان‌های اجراشده است، نه گواهی دقت بالینی، امنیت جامع یا سازگاری همه مرورگرها.

## سناریوهای علمی کلیدی آزموده‌شده

- تفاوت D در ۷۰ و ۷۱ سال؛ تفاوت B6 در ۵۰ و ۵۱ سال.
- مرجع بارداری/شیردهی و رد ترکیب‌های خارج از جدول اجراشده.
- افزودن ۳۵ mg برای C در فرد سیگاری.
- ۶۰۰ IU ویتامین D برابر ۱۵ mcg.
- ۴۰۰ mcg اسیدفولیک همراه غذا برابر حدود ۶۶۶٫۶۷ mcg DFE؛ مقدار قابل مقایسه با UL همچنان ۴۰۰ mcg اسیدفولیک.
- عدم اعمال UL رتینول به کاروتنوئید غذایی و اعلام ناقص بودن ارزیابی شکل نامعلوم A.
- عدم اعمال UL نیاسین/ویتامین E مکملی به نمونه غذایی طبیعی.
- هشدار B6 بالاتر از ۱۲ mg اروپا، حتی زیر UL آمریکا.
- تفاوت نبود داده و مقدار ثبت‌شده صفر.
- رد مقدار منفی، بی‌نهایت، واحد نامتناسب و فایل نامعتبر.
- escape نام واردشده حاوی HTML؛ ذخیره تنها پس از انتخاب کاربر.

## چک کوتاه قبل از استفاده عمومی

۱. سایت را روی Chrome، Firefox و Safari باز کنید؛ منو و صفحه‌کلید را بررسی کنید.

۲. در عرض‌های ۳۶۰، ۷۶۸ و ۱۴۴۰ پیکسل، فرم و جدول مقایسه را مرور کنید. روی موبایل جدول باید در قاب خود اسکرول شود.

۳. در محاسبه C، یک پرتقال ثبت کنید؛ برای زن ۳۰ سال در حالت معمول، مقدار ۷۰ mg و نسبت حدود ۹۳٫۳۳٪ انتظار می‌رود.

۴. در D، دریافت ۵۰۰۰ IU مکمل ثبت کنید؛ مقدار ۱۲۵ mcg و هشدار عبور از UL آمریکا باید نمایش داده شود. این سناریو صرفاً برای تست نرم‌افزار است.

۵. ورودی سن ۱۲ را امتحان کنید؛ باید پیام عدم پشتیبانی کودکان بگیرید و مشخصات پیشین باقی بماند.

۶. از فضای کار پشتیبان بگیرید، همه را پاک کنید و بازیابی را با تأیید جایگزینی انجام دهید. با ذخیره خودکار خاموش، بازخوانی صفحه نباید جلسه را نگه دارد.

۷. چاپ را روی A4 و Save as PDF بررسی کنید؛ منو نباید در گزارش چاپ شود و اطلاعات نباید بریده شوند.

۸. پیوند منابع را باز و مقدار، واحد، نوع فرم و دامنه UL را با بازبین مستقل تطبیق دهید.

## موارد خارج از دامنه این انتشار

نسخه فعلی برای ثبت یک جلسه است و تاریخچه چندروزه/چندبیمار، احراز هویت، تجویز مکمل، تفسیر خودکار آزمایش و داده کامل همه غذاها را ارائه نمی‌کند. API غذایی زنده و API هوش مصنوعی ندارد. برای نشر بالینی، بازبینی داده، آزمون کاربری، ممیزی دسترس‌پذیری، امنیت و الزامات محل فعالیت باید تکمیل شوند.

## بازتولید بررسی‌ها

```bash
npm run build
```

آزمون‌ها وابستگی خارجی ندارند و با Node.js ۲۰ یا جدیدتر اجرا می‌شوند. خروجی آزمون همان کدی را بررسی می‌کند که در `dist` میزبانی می‌شود. نسخه پروژه با Git قابل ثبت و بازگشت است.
